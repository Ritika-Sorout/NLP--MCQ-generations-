# NLP MCQ-generations
Serenity is a minimalistic web application that leverages Natural Language Processing (NLP) to: - Generate summaries of input text. - Generate relevant questions for the given input.
## 🔧 Technologies Used
- Python
- Flask (for backend)
- HTML, CSS (for frontend)
- Transformers (T5 model)
- Sentence Transformers
- Pickle (for saving models)

## ✨ Features
- Text summarization using T5-base.
- Question generation using T5 fine-tuned on SQuAD.
- Aesthetic UI with calming blue and cream colors.
- Model persistence using Pickle for offline reuse.

## 🛠️ How to Run
1. Clone the repo:
```bash
git clone https://github.com/yourusername/SerenityWebsite.git
```

2. Navigate to the project directory and install dependencies:
```bash
pip install -r requirements.txt
```
3. Run the Flask app:
```bash
python app.py
```
4. Open `localhost:5000` in your browser.
